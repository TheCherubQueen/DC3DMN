# Description
This was part of my final year coursework for a data mining module, where we were given a poor quality dataset containing COVID-19 test results and multiple other attributes for a patient and tasked to create the best possible predictions over an unseen dataset. This was very challenging given how poor the input data was. The grade was given for the predictions overall F1 score as well as the accompanying write up. The highest F1 score attained in the class was 0.2230 and my result with this repository was 0.1985 (89%). The report scored 69/100 also making the overall grade for this (accounting for weighting of F1 vs Report) of 75% (in UK university terms this is working at the equivalent of a 1st)
